## 1. Traceability Methodology & Status Taxonomy

Never equate the mere presence of source code or library imports with a completed requirement. Requirements are evaluated across five distinct verification tiers:
1. **Static Implementation:** Is valid code written and structurally complete?
2. **Runtime Integration:** Is the component wired into the active operational pipeline (`module8_dashboard/backend`)?
3. **Automated Verification:** Does an automated test in `tests/` exercise the logic under positive and negative conditions?
4. **Empirical Evaluation:** Is there scientific benchmark evidence (precision/recall, ROC-AUC, EER, mAP, latency distributions) on held-out datasets?
5. **Scope Compliance:** Does the deliverable align with the approved software-only pivot?

### Standard Status Labels

| Status Label | Formal Definition |
|---|---|
| **VERIFIED COMPLETE** | Implemented in active runtime, tested via automated test suite, empirically benchmarked on real data, and fully meets requirements. |
| **IMPLEMENTED BUT UNVALIDATED** | Fully implemented in the active runtime and passes functional tests, but lacks scientific accuracy benchmarks on held-out datasets. |
| **PARTIALLY IMPLEMENTED** | Component exists in the active runtime with functional limitations, degraded heuristics, or missing sub-features. |
| **LEGACY ONLY / NOT INTEGRATED** | Code exists in legacy folders (`module1_face_recognition`, `module2_vehicle`), but is disconnected from the operational dashboard backend. |
| **PLACEHOLDER OR MOCK** | Component returns simulated values, fixed constants, or static string templates rather than executing real model inference. |
| **NOT IMPLEMENTED** | Requirement was proposed in SRS/proposals but has no executable implementation in either active or legacy codebases. |
| **FORMALLY DEFERRED** | Requirement was documented as deferred to future work via official change request or documented delivery plan. |
| **OUT OF REVISED SCOPE** | Physical hardware requirement eliminated by the strategic software-only pivot. |
| **UNVERIFIABLE** | Claim cannot be validated due to lack of specified acceptance criteria, missing ground truth data, or environmental impossibility. |
